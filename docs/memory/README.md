# Claude memory notes

Copies of Claude Code's memory notes for this project, so they travel with the repo.
On a new machine, copy the `.md` files here into Claude Code's memory folder for this project:
`~/.claude/projects/<project-folder-slug>/memory/` (the slug is the repo path with separators as `-`,
e.g. `C--Users-<you>-urbandata`). `MEMORY.md` is the index Claude loads each session.

The task list to pick up is in [../TASKS.md](../TASKS.md).
