## Checking a change

```sh
npx tsc --noEmit -p .        # types
npx vite build               # build + 146 prerendered pages
npm run dev                  # dev server; the drawing check expects localhost:4402
node tools/pro/drawings-check.mjs <outdir> 9481                       # sample scheme
node tools/pro/drawings-check.mjs <outdir> 9482 - "Tapered tower"     # a formed tower
node tools/pro/drawings-check.mjs <outdir> 9483 - "" mumbai           # Mumbai rules
```

Use a fresh port each run. The script saves every sheet as PNG and the downloaded PDF.
Render the PDF pages to look at them, e.g. with PyMuPDF (`page.get_pixmap(dpi=110)`).

## Done recently

- **Approval drawings (Pro → Approve step):** an A3 PDF set, downloaded directly; the
  PreDCR DXF is a side option. Cover, site plan, typical floor plan, formed floor plans,
  parking plans per level, elevation, Section A–A, area statement, schedules, scrutiny.
- **Drawing detail (`b94f008`):** stairs (flights, treads, landings, width, risers), lift
  shafts with cars and the fire lift, fire-check/common lobbies, ducts
  (`src/pro/coreDetail.ts`); walls at 230/115 mm; door swings; room length × width;
  section line A–A; the DXF puts stairs and lifts on `_Staircase` / `_Liftwell`.
- **Cadastre harvester:** `npm run cadastre -- --village <giscode>` or `--taluka U,25,16,`
  (resumable, writes GeoJSON to `data/raw/cadastre`). Tested on Mundhawa.

## Next: approval drawings

1. **Larger sheets.** Plans are submitted at 1:100 on A1/A0; on A3 we reach 1:200.
   Add a sheet size option (A3 / A1 / A0) to the PDF.
2. **Ground floor / entrance plan:** entrance lobby, letter boxes, the security cabin,
   meter room, the stilt with the core coming down.
3. **Terrace plan:** the parapet, lift machine room, the stair head room, water tanks, solar.
4. **Refuge floor plan** for buildings over 70 m (UDCPR/DCPR refuge area every ~7 floors).
5. **Real elevations:** windows, balconies and doors on the faces, not floor bands.
6. **Site services on the site plan:** drainage and septic/sewer, water connection,
   rainwater harvesting pits, solar, tree planting with counts.
7. **Core layout is generated by rule.** Let the user adjust it (swap stair/lift order,
   move the duct) and carry that into drawings and DXF.
8. **Assumed values to make settings:** lift pit 1.5 m, machine room 3.0 m, basement
   height 3.3 m, slab 150 mm, parapet 1.0 m (all labelled "as assumed" on the sheets).
9. Section A–A cuts through the first core of each building only; add a second section
   (B–B) across the other axis.
10. Minor: in `coreDetail.ts`, `cap: (service && i === 0 ? cap : cap)` is redundant;
    a service lift should take its own (larger) capacity.
